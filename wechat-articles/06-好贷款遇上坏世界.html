GPU、子宫与印钞机（六）｜好贷款遇上坏世界

「GPU、子宫与印钞机」AI时代命运推演 · 系列连载

文 | Tony Seah

前五篇我们聊了AI怎么吃掉白领工作、怎么把消费者变成"僵尸户"、怎么让生育率再跌一个台阶。但这些冲击波最终都会汇到同一个地方——金融体系。

当中产不再消费、不再还贷、不再交税，整个经济循环的地基就开始松动。

今天我们来拆解这根链条：从一笔好贷款开始，到银行倒闭、城市衰退、政府印钱续命——直到赌场变成最后的避风港。

2008年的核心问题是：贷款从第一天就是坏的。这一次完全不同——贷款在签出那天是好的，只是世界在贷款签出之后，变了。

一、好贷款遇上坏世界

美国住房按揭市场规模13万亿美元 [1]。

这些借款人FICO评分780分，首付20%，信用完美。跟2008年那帮根本不具备偿还能力的次贷借款人完全不同。那一次是贷款本身就烂了；这一次，是贷款签完之后，整个世界变了。

看看部分AI冲击较早的城市（2024-2025年数据）：旧金山房价同比下跌11%，西雅图下跌9%，奥斯汀下跌8% [1]。房价涨跌本是常态，这里呈现的是特定时期的截面，不代表长期趋势。

白领降薪降档之后，靠信用卡透支和401(k)提前取现勉强维持还贷。技术上"还在还款"，但已经停止了所有非必要消费。数据上不算违约，但实质上已经退出了经济循环。这些人有一个名字：僵尸户。

往下推演三层，你会发现每一层都在放大冲击。

第一层：财富效应。

在美国，房子是中产阶级最大的资产。房价下跌让人们觉得自己变穷了——即使还没失业，也会缩减消费。这种心理效应会放大实际经济收缩。你本来可能只是看新闻时有点焦虑，结果你取消了旅行计划、推迟了换车、不去餐厅吃饭了。乘以几千万户家庭，这就是衰退。

第二层：地方财政。

美国的公立学校、消防、警察主要靠房产税。旧金山房价跌11%，意味着学校预算被砍、老师被裁、班级合并、教育质量下降。有钱人把孩子转去私立学校，穷人的孩子困在一个越来越差的公立系统里。

在这个链条下，AI冲击有可能间接加剧教育不平等——尽管这并非唯一的走向。AI本身也可能成为教育的平权工具：一个孩子只要用上ChatGPT或Claude，就有了一个无限耐心的私教，这在以前是富人才负担得起的。关键在于：学校预算被砍之后，那些最需要帮助的孩子，能不能用得上这些工具。

第三层：科技城市的脆弱性。

房价下跌最严重的城市恰好是科技城市——旧金山、西雅图、奥斯汀。这些城市过去十年的繁荣完全靠科技行业支撑。链条是这样的：

科技业裁员 → 房价跌 → 餐馆关门 → 服务业裁员 → 人口外流 → 税基萎缩 → 基础设施恶化。

底特律花了三十年经历的衰败 [17]，旧金山可能五年就走完。

三大经济体按揭全景：25万亿美元的多米诺

上面只讲了美国。把镜头拉远——这是一个25万亿美元级别的跨国问题。

经济体按揭存量危机状态
美国$13.1万亿（2026Q2，纽约联储）未来风险（AI驱动）
欧元区€5.50万亿 ≈ $6.4万亿（2026年6月，ECB）相对稳定
天朝¥36.29万亿 ≈ $5.4万亿（2026Q2，央行）已经在发生

三项合计约25万亿美元（按ECB 2026年8月参考汇率折算：1欧元=1.1605美元、1美元=6.74元人民币）。这不是一个外部统计口径，而是三项官方数据的加总；若再算上英国与非欧元区欧洲市场，规模还要更大。

美国的按揭危机还停留在推演阶段。但天朝的？它已经进入第五个年头了。

天朝：多重压力叠加，调整仍在持续

美国的故事是"AI可能让好贷款变坏"。天朝的故事更复杂，也更紧迫——房地产系统本身就有结构性缺陷，AI冲击只会让它雪上加霜。

头部房企陆续进入债务重组。 过去几年，多家大型开发商先后出现债务压力——有的进入司法清算程序，有的正在推进债务重组，有的在评级机构调整后努力维持经营 [118]。这不是个别企业的经营失误，而是整个行业在经历深度调整。

预售制带来的交付压力。 天朝的"预售制"允许开发商在房子还没建好时就收款。当部分开发商资金链紧张后，一些已经付了首付甚至开始还贷的购房者面临房屋延期交付的困境。2022年前后，多个城市出现了购房者要求加快交付的集中诉求 [119]。据估计仍有相当数量的已售住房尚未完成交付 [119]。政府已出台多项保交楼政策并投入专项资金，但从项目层面看，部分地区的资金缺口仍需时间弥合。

房价持续调整，但跌法在分化。 2026年2月，70个城市新房价格同比下跌3.2% [120]。到2026年7月，分层数据显示跌势正在向低线城市与二手房集中：新房同比一线-1.1%、二线-2.8%、三线-4.2%；二手房一线-3.7%、二线-5.1%、三线-5.8% [120]。和年初相比，一线在修复——一线二手房同比从2月的-7.6%收窄到7月的-3.7%，7月环比甚至转正+0.2%——但三线新房反而从-4.0%走阔到-4.2%。修复只发生在核心城市。 2025年全国新建商品房销售额降至8.39万亿元（同比-12.6%），约为2021年高点的46% [120]。房价涨跌是市场常态，但持续数年的调整对家庭资产负债表的影响值得关注。

库存消化需要时间。 全国空置住房数量较大，二三线城市库存消化周期偏长 [20]。

家庭正在主动去杠杆。 个人住房贷款余额连续多年下降，不少家庭选择提前还贷 [121]。家庭的优先级从扩张消费转向了降低负债——这和1990年代日本经历的"资产负债表调整"有相似之处。

现在叠加AI冲击。 天朝面临的不是一重压力，而是三重叠加：

1. 存量危机（已发生）：烂尾楼、开发商违约、房价下跌

2. 人口危机（正在加速）：2022年起人口负增长，需求端持续萎缩

3. AI就业危机（即将到来）：白领收入下降 → 按揭断供 → 从"开发商的危机"变成"家庭的危机"

美国的按揭问题是"好贷款遇上坏世界"——一个尚未发生的假设。天朝的按揭问题是"结构性缺陷遇上人口持续萎缩再遇上AI冲击"——一个已经在显现、且面临进一步压力的现实。

二、中产断供，然后呢？

中产阶级是现代经济体系的支柱。他们买房、消费、交税、还贷——整个系统的循环靠他们转。当中产没了收入，第一张倒下的多米诺骨牌，是银行。

先看商业地产。美国有近1万亿美元的商业地产贷款在2026年到期 [16]，其中五分之一是办公楼。这些贷款当初是按"办公室永远会有人坐"来定价的。现在旧金山办公楼空置率34% [15]。借款方还不起，银行要么续贷（假装没事），要么认损（资产负债表被炸穿）。

但商业地产还不是最要命的。

住宅按揭才是真正的定时炸弹。中产白领的断供不同于2008年的次贷——这次是从"能还"变成"还不起"。而中产的贷款金额远大于次贷：一套旧金山的房子200万美元，首付40万，贷款160万。这种级别的坏账，区域银行根本扛不住。

哪些银行最危险？

不是华尔街的巨头——摩根大通、高盛的业务足够分散。危险的是区域银行。美国有几千家区域银行，资产集中在本地房贷和商业地产。当一个城市的支柱产业崩了，本地银行就跟着崩。

2023年硅谷银行倒闭只是预演 [16]。接下来可能是一连串区域银行的倒闭潮。FDIC能救几家，但救不了几百家。

银行一倒，信贷冻结，城市基础设施开始老化却无钱维修。

这就是去城市化的起点。

三、双速城市：有的在死，有的在变形

去城市化不是新概念。

底特律从185万人口缩减到68万，用了65年 [17]。克利夫兰联储的研究详细记录了美国"锈带"城市的衰退轨迹 [18]。天朝东北已经在经历类似的过程——辽宁的年轻人月薪三四千，大学毕业不回来；鹤岗的房子两三万一套没人要 [19]。国内目前有超过5000万套空置住房 [20]。

但过去的去城市化是缓慢的、局部的——一个行业没了，一个地区衰落。

AI驱动的去城市化可能是快速的、广泛的。

而且这次不只是蓝领城市。过去去城市化发生在工厂关闭的地方——底特律、匹兹堡 [18]。这次会发生在白领集中的地方——达拉斯的金融区、亚特兰大的企业总部园区、国内无数个"新区"和"开发区"。一个白领岗位的消失，大约会拖倒3-5个服务业岗位。

如果这些趋势持续，一种可能的演化路径是"双速"格局。

普通城市——快速衰退

那些靠单一产业或政府转移支付维持的中小城市，中产失业后消费崩塌、商铺关门、房价暴跌、银行坏账飙升、地方财政破产、公共服务萎缩、年轻人和有能力的人离开，留下走不了的老人和穷人。

Rust Belt花了三十年走完的路 [18]，AI时代的普通城市可能五到十年就走完。

核心城市——慢一点，但也会变形

旧金山、纽约、北京、上海——这些城市有一个普通城市没有的东西：多样性和网络效应。

它们不会消亡，但会从"大量中产工作的城市"变成"少数极高产出的AI精英 + 大量服务业底层"的城市。人口可能减少一半，但GDP反而增长——因为剩下的人（和AI）的产出极高。

你会看到一种奇怪的景观：城市中心几栋超级写字楼灯火通明，周围十几个街区半空着、商铺拉着卷帘门。

像一个心脏还在跳、四肢已经冷了的身体。

天朝：城市化压力可能更集中

过去二十年，天朝的城市化是人类历史上规模最大的一次人口流动——几亿人从农村进入城市，推动了房价和经济的快速扩张。这套模式运转的前提，是"城市持续有工作"。

一线城市相对有韧性——北京、上海、深圳背靠AI产业和政策资源。但大量三四线城市的经济，长期依赖地方政府投资、房地产开发和为大城市配套的制造业，这三个支撑在AI时代都面临不确定性 [19][20]。

如果白领就业持续承压，加上房地产的存量调整尚未出清，部分城市可能走上和鹤岗类似的路——人口外流、房价低迷、服务业萎缩。这二十年建立的城市化格局，在未来十年有可能进入一个再分布的阶段。

人去了哪？

城市收缩了，人不会凭空消失。但他们也不会回到农村——农村没有工作、没有医院、没有学校。

核心逻辑是：往生活成本更低、但仍有基本基础设施的地方迁移。

各国的路径可能不同。美国已经在发生：加州和纽约的人涌向德州、田纳西、爱达荷的二线城市——Boise、Nashville、Tulsa这些地方的房价和人口都在涨。远程办公让这条路走得通：你不需要住在公司附近，只需要有网络。天朝的路径更复杂。"逃离北上广"已经说了十年，一线城市的年轻人回流省会和地级市老家。但如果这些城市本身也没有工作呢？很可能变成"从一个没机会的地方挪到另一个没机会但便宜一点的地方"。日本是另一种极端——东京反而在虹吸全国人口，其他城市持续萎缩。年轻人不是回乡，而是更集中到唯一还有机会的地方。欧洲则出现了双向流动：南欧年轻人往北欧跑去找工作，同时北欧的远程工作者去葡萄牙、希腊享受低成本生活——数字游民签证就是这个趋势的产物。

无论哪种路径，共同点是：城市化不会简单逆转为"回农村"，而是重新洗牌——人口从高成本城市流向低成本但仍能维持基本生活的地方。 如果远程办公在AI时代成为常态，这种重新分布只会加速。

不是普通的经济下行

这里需要特别说明一件事：AI导致的失业，可能不是一个普通的经济周期。

以往的衰退——2001年互联网泡沫、2008年金融危机——失业是暂时的。经济恢复了，岗位就回来了，可能换了个名字，但本质上人还是被需要的。

AI不一样。它替代的不是某个行业的某个环节，而是"人类执行认知任务"这件事本身。一个被AI替代的法律助理，不是在等经济好转后回去上班——那个岗位永远不会回来了。一个被AI取代的初级分析师，不是"暂时失业"——他的技能本身贬值了。

这意味着什么？

一部分人会转型成功——学会和AI协作，找到新的定位。但不是所有人都能转型。不是因为他们不够努力或不够聪明，而是因为当AI能做80%的认知工作时，剩下的20%不需要那么多人。

对于长期找不到工作的人，轨迹可能是这样的：先靠积蓄和遣散费撑几个月，然后开始削减开支、搬到更便宜的地方、提前取出退休金。一年后积蓄耗尽，开始依赖政府救济或家人接济。心理上，长期失业带来的不只是经济压力，还有身份认同的崩塌——"我是谁？我还有什么用？"这种状态如果持续两三年，抑郁、家庭破裂、健康恶化会接踵而来。

这不是危言耸听。美国"锈带"城市在去工业化后经历的正是这个过程——只不过那次用了二三十年，波及的是蓝领。这次可能更快、波及的是白领，而白领的房贷和生活成本比蓝领高得多，摔得也更重。

所以前面讨论的城市衰退、银行坏账、政府印钱——这些不是抽象的宏观数字。每一个数据点背后，都是一个具体的人在经历从"有体面工作"到"不知道明天怎么办"的过程。而且这个过程可能没有尽头——不是"熬几年就好了"，而是"旧世界的规则永久性地变了"。

四、私人信贷：藏在保险公司里的炸弹

金融体系还隐藏着另一颗定时炸弹。

过去十年，华尔街把保险公司变成了融资工具：Apollo买了Athene，KKR收了Global Atlantic——用普通家庭的年金去投PE支持的软件债 [1]。

翻译一下：你爸妈的养老钱，被拿去给科技公司放贷了。

当软件公司因AI冲击而违约，受伤的不是华尔街的交易员——他们早就对冲了风险。受伤的是普通家庭的退休金。

这不是假设。Zendesk的违约——50亿美元ARR支撑的贷款——已经成为史上最大的私人信贷软件违约案例 [1]。所谓"永久资本"的真相，是普通人的年金。

标普从高点回撤38%，可能最终接近-57% [1]——回到ChatGPT诞生前的水平。

换句话说，AI创造的全部市值，可能被AI摧毁的经济全部抹掉。好像ChatGPT这三年的财富效应，只是一场梦。

五、金融链的自我强化：为什么这次不会自动复原

上面说的断供、银行、城市、私人信贷，每一层都不是孤立的事件。它们之间存在几个自我强化的机制，让这条链一旦开始转动，就很难在外力介入之前自行停下。

债务通缩螺旋：费雪1933年的预言

欧文·费雪在大萧条期间提出了一个让人不寒而栗的机制：

资产价格跌 → 债务人被迫抛售资产还贷 → 资产价格进一步跌 → 债务的实际价值反而上升（因为通缩让钱变值钱了）→ 更多人还不起 → 继续抛售。

这个螺旋一旦启动，会自我强化，直到某个外部力量打断它。大萧条就是这么来的。

AI时代的版本：初始触发点从"银行挤兑"换成了"白领失业"，但螺旋结构完全一样。通缩最隐蔽的地方在于：你欠的是名义上的固定数字，但通缩让这个数字的实际购买力越来越重。即使利率没变，你的实际还款压力在悄悄增加。

养老金死循环：底特律的慢性病

AI带来的税基侵蚀，杀伤力最强的地方不是联邦政府，而是地方政府。

美国的市政养老金（CalPERS、教师养老金等）精算假设年化回报7%。低增长+通缩环境下，这个假设直接破产。地方政府被迫填补养老金缺口 → 砍警察、砍消防、砍学校预算 → 城市宜居性下降 → 有能力的人和企业迁走 → 税基进一步萎缩 → 养老金缺口进一步扩大。

这是一个完整的正反馈死循环。底特律2013年破产，养老金负担是核心原因之一。AI时代，这个剧本可能在更多城市重演——而且速度快得多。

政府收入跌、支出涨的大背景，以及印钱这个几乎必然到来的"解法"，下一篇再谈。

地理流动性陷阱：走不了的人

衰退城市里有一群被困住的人。

想走，但房子卖不掉。整个城市的人都想卖，没有人想买，房子挂出去没有接盘的。你不是不想离开，是离开不了——资产被锁死在一个dying city里。

这个机制底特律已经验证过：大量房产无人问津，居民无法通过卖房变现再迁居他处。与此同时，还在租房的年轻人反而流动性更强——但他们面对的是另一重困境：职业路径受阻、收入下降、没有资产缓冲，是这轮冲击里缓冲最薄的一群。

几个被低估的加速器

还有几条链条值得一提：

HELOC断了小企业的命。 美国大量小企业主用房屋净值贷款（HELOC）当营运资本。房价跌 → 净值消失 → 银行撤销额度 → 小企业失去流动性 → 关门裁员 → 更多断供。2008年这条链发生过，这次可能更难被低利率托住。

婴儿潮卖房给谁？ 美国最大一批房主正在进入退休年龄，养老计划很大程度上依赖卖房套现。买家本该是35-45岁的中产白领。但如果这批白领正在经历AI失业和降薪……供给增加遇上需求塌陷，是一个双向做空房价的结构性力量。

节约悖论的AI版本。 凯恩斯说：所有人同时省钱，总储蓄反而下降，因为经济在萎缩。AI版本是：所有公司同时用AI砍成本，集体消灭了自己客户的收入，需求崩塌，营收反而下降。每家公司都是理性的，整体是自杀式的。

富人抄底，中产变租客。 危机中有流动性的资本会大规模收购廉价法拍房产。这不是推演——2012年后Blackstone等机构在全美大量买入法拍房，成为最大的单户住宅房东。下一轮危机，配备AI定价工具的大资本可以更快、更准地扫货。中产破产 → 房产易主 → 原来的业主变成租客。资本对劳动的胜利，在房产市场上被永久性地固化。

小结

这篇文章拆解了一根完整的金融冲击链，以及让它自我强化的几个机制：

好贷款变成坏贷款 → 中产断供 → 区域银行倒闭 → 城市衰退 → 私人信贷连锁引爆 → 债务通缩螺旋 → 地方政府养老金死循环 → 城市锁死。

每一环都不是独立事件，而是上一环可能引发的结果。整条链的起点，只是一个AI代理替代了一个产品经理。

以上是一种推演路径，不是必然发生的剧本。每一环之间都有政策干预的窗口——大萧条、日本失去的二十年、底特律的慢性死亡，都曾经有人预判过、也都有人试图阻止过。

当这条链开始转动，所有人都会看向政府：你们打算怎么办？
